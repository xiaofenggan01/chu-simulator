# A 畜模拟器

一款讽刺向像素网页游戏：你将扮演 Anthropic「Safeguards Team」的安全审查员达里奥的下属，从聊天记录、支付凭证、考勤日历、开发环境里找线索，找出潜藏的中国大陆用户并盖章「封禁」。

> **本作品为讽刺戏仿（parody），与 Anthropic 无关。** 玩法影射的是 2025-2026 年间大量中文用户被无差别封禁的现象——游戏里的「审查员」才是被讽刺的对象。

## 玩法

### 值班速裁（主模式）
12 位来访用户依次递上 5 句对话卷宗。读对话，判断里面藏的是中国大陆制度细节（公摊面积、调休补班、烂尾楼月供、N+1……）还是境外华人的生活痕迹（组屋、工作签证抽签、温哥华家庭医生……），盖「封禁」或「放行」章。判定标准不是「惨不惨」，而是制度名词的地理归属。

### 进阶断案（完成一轮速裁后解锁）
五案剧情模式，每案一块证物软木板：

1. **人在美国，刚下高铁** —— 会话打印件 / 站台拍立得 / 设备检查单
2. **美区账号，银联付款** —— 联系人登记表 / 实体银行卡 / 支付回执
3. **周日怎么还在上班** —— 调休日历 / 用量报表 / 应用检查单
4. **新加坡公司，粤 ICP 备案** —— 申请表 / 营业执照 / 备案证书
5. **npm 换源，当场抓获** —— settings.json / 终端纸 / 屏幕快照

在证物上点击取证（有动画飞入线索栏），集满后展开推理板：把两张线索卡拖上「反应台」点推理——组合有效则爆闪出新推论，无效则达里奥掉 1 滴血。链式推导直到「用户人在中国大陆」结案。

### 达里奥血条
搭档达里奥·阿莫迪的像素血条是容错资源：无效推理、使用提示都会扣血，血尽殉职、本局作废。

## 本地运行

纯静态站（原生 ES Modules，无构建、无依赖）：

```bash
python3 nocache-server.py 8747
# 打开 http://127.0.0.1:8747
```

> 必须用自带的 `nocache-server.py`（禁用缓存头）；系统 `http.server` 的启发式缓存会让你改代码后看到旧版本。

## 部署

任意静态托管皆可。以 Cloudflare Workers 为例：

```bash
rm -rf dist && mkdir dist && cp index.html dist/ && cp -r css js assets dist/
wrangler deploy   # wrangler.jsonc 已配好静态资产
```

## 技术栈

原生 HTML/CSS/JS（ES Modules）＋ SVG sprite 图标 ＋ CSS 像素风。零依赖、零框架、单 CSS 文件。素材为 AI 生成后 WebP 压缩（合计 &lt;2MB）。
